Branch (this device)

"Push new parts to Firestore" adds any part that doesn't exist in Firestore for this branch yet, repairs incomplete records, and reactivates parts stuck marked archived in Firestore even though they're active locally. It never touches a part that's already fine there.

If this device isn't the only one used to sell or manage stock, run "Pull latest stock from Firestore" regularly (start of shift is a good habit) — it brings in quantity changes made by other devices (other admins, cashiers) that this device wouldn't otherwise know about. "Push new parts" only sends this device's own changes out; it doesn't bring anything in.
